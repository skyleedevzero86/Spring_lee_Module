Admin Portal

user-portal과 다른 OAuth2 Client입니다. auth-server 세션이 있으면 비밀번호 없이 SSO로 들어오고, ROLE_ADMIN이 없으면 403 / Access Denied가 납니다.

로그인에 실패했습니다. 아래 버튼으로 처음부터 다시 시도하세요. (콜백 URL을 새로고침하지 마세요)

auth-server로 관리자 로그인
  • Client: admin-portal
  • Required: ROLE_ADMIN + scope admin
  • Redirect: http://localhost:8082/login/oauth2/code/admin-portal
  • SSO: user-portal 로그인 후 이 페이지에서 재로그인 없이 인증됨
